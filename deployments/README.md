# 📦 Deployments

This folder stores deployed contract addresses for different networks.

## 📁 Files

### `localhost.json`

This file is automatically generated by `scripts/deployAll.js`.

It contains the addresses of all deployed contracts on the local Hardhat network.

Example:

```json
{
  "IssuerRegistry": "0x...",
  "CredentialRegistry": "0x...",
  "DiplomaVerifier": "0x..."
}
```
Usage

Scripts such as: `demoFlow.js`, `demoMerkleProof.js` read this file to load contract addresses dynamically instead of hardcoding them.
